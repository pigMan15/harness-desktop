# Knowledge 执行区自适应布局

## 问题

Knowledge 页面固定使用左右双栏。当 Codex 未运行、没有 Diff 和日志时，右栏卡片下方形成大面积留白，左侧候选卡片无法利用该宽度。

## 实现

- 新增执行区折叠状态，页面初始为空闲全宽布局。
- 折叠时主区域占满整行，候选卡片的 auto-fill 网格自动利用更多横向空间。
- 空闲状态显示紧凑的“Codex 执行器待命”横向提示，不渲染右侧空卡片。
- 运行 Codex、恢复活动会话、生成 Draft 或收到 Preview 时自动切换到左右分栏。
- 右侧增加“执行工作台”工具栏，可在执行结束后手动收起，并可从横向提示重新展开历史结果。
- Codex 运行中或存在待审批请求时禁用收起，防止授权入口被隐藏。
- Push via App 成功后自动恢复全宽布局；启动失败也恢复全宽。

## 预期行为

- 空闲：仓库配置、状态条和候选列表全宽展示，不再保留右侧空白列。
- 运行/预览：右侧自动展开 Diff、日志、审批和人工反馈。
- 完成：用户可收起执行区，或在推送成功后自动收起。
